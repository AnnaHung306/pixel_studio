# 04 系統架構

## 前端（public/，原生 ES modules，無框架）
| 模組 | 職責 |
|---|---|
| main.js | 啟動、全域事件、手勢 |
| state.js | 文件模型（圖層、影格、cel）、歷史紀錄 |
| core/raster.js | 像素運算（筆刷、填色、形狀、混合） |
| core/palettes.js | 內建調色盤 |
| tools.js | 繪圖工具狀態機 |
| view.js | 畫布繪製、縮放平移、指標事件 |
| panels.js / dialogs.js / dom.js | UI 面板、對話框、DOM 工具 |
| actions.js | 指令（選單、快捷鍵） |
| formats.js / io.js | 匯入匯出（PNG、APNG、GIF、ZIP、.pxs、.gpl、.hex） |
| storage.js | IndexedDB 自動存放 |
| cloud.js | 與本機伺服器同步（WebSocket） |
| version.js | 建置時由 package.json 產生的 `APP_VERSION`（關於、匯出 metadata） |
| sw.js | Service Worker 離線快取（快取名 `pixel-studio-<版本>-<內容雜湊>`） |

建置：`scripts/build.js` 將 public/ 輸出到 dist/。

## 伺服器（server/，Node ≥ 20，Express + ws）
| 模組 | 職責 |
|---|---|
| index.js | HTTP、WebSocket、靜態檔 |
| store.js | 專案儲存（data/） |
| ops.js | 繪圖操作（AI 共用） |
| mcp.js | MCP Streamable HTTP 端點（15 工具，無刪除） |
| openapi.js | OpenAPI 3 規格、/docs |
| png.js | PNG 編碼 |
| version.js | 讀 package.json 的版本（/api/health、MCP serverInfo、OpenAPI info） |

## 觸控介面（1.1.0，ADR-002）
啟動時 `applyTouchClass()` 對 iOS／iPadOS 或 coarse 指標加 `html.touch`；所有觸控尺寸集中在 `app.css` 的 `html.touch` 區塊，時間軸 `CW`／`LH_W` 由 `panels.js` 依此放大。`dom.js h()` 為只有符號的按鈕自動加 `aria-label`。

## 自動儲存狀態機（1.2.0）
`main.js`：saved → dirty（任何 `dirty` 事件，800ms 去抖）→ saving → saved｜error。儲存中若文件版本又變，完成後回到 dirty 並接續儲存；error 時顯示 `#save-banner`（備份／重試／管理專案）並以 4s→60s 倍增自動重試。`storage.js` 的 `faults.save` 供 e2e 故障注入。狀態反映在 `#doc-title[data-save]` 與 `#save-status`（live region）。

## 復原歷史與記憶體預算（1.3.0，ADR-003）
`state.js`：`historyBytes()` 計算只被歷史保留的不重複緩衝區；`enforceHistoryBudget()` 於每次 commit（含 cloud.js 的遠端／AI 寫入）後執行。預算 iOS 96 MB／低記憶體 128 MB／其他 320 MB，步數上限 200，至少保留 10 步。

## 單元測試（1.3.0）
`tests/unit/*.test.js`（node:test），`npm test`：raster、formats、palettes、.pxs、history。

## 診斷（1.4.0）
`diag.js`：100 筆環狀紀錄（全域 error／unhandledrejection、自動儲存失敗、啟動），`environment()` 收集裝置、快取、儲存、專案規模（不含像素資料），`formatReport()` 產生可複製文字；「☰ → 診斷資訊」可複製或下載 JSON。絕不自動上傳。

## Apple Pencil 與 Scribble（1.4.0）
`dom.js claimPencil(el)`：繪圖面（畫布、取色器）掛 non-passive `touchmove` 並 `preventDefault()`，避免 iPadOS Scribble 攔截快速筆畫（WebKit Bug 217430）；捲動面板不掛。

## 資料安全提示與 IndexedDB 重連（1.5.0，ADR-006）
`notices.js`：`pick()`（純函式）依 iOS／主畫面模式、延後時間、最後備份、首次使用決定顯示 `install` 或 `backup`；`#notice-bar` 位於頂端列下方。設定鍵：`firstUseAt`、`lastBackupAt`、`installNoticeSnooze`、`backupNoticeSnooze`。`io.exportPxs()` 記錄備份時間。`storage.js` 連線關閉時清除快取並在 InvalidStateError 時重開重試一次。

## 專注模式（1.6.0，ADR-007）
`#app.focus` 以 CSS 隱藏 `#topbar/#optionsbar/#sidepanel/#timeline/#notice-bar`，顯示 `#focus-pill`（復原、重做、離開）；`main.js toggleFocus()` 切換 class、`aria-pressed`、收起手機面板並 `fitView()`。純視圖狀態，不寫入專案或設定。

## 一次性工具（1.7.0）
`app.ui.oneShot`（'eyedropper'|'eraser'|null）：`tools.down()` 對繪圖類工具覆寫為該工具，`up()` 結束後清除；按鈕 `#qt-pick/#qt-erase` 於 `main.js` 綁定。

## 待補（隨迭代更新）
