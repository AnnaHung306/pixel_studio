# 05 測試計畫

## 1. 測試層級
| 層級 | 工具 | 範圍 |
|---|---|---|
| 單元 | `npm test`（node:test，1.3.0 導入） | core/raster、formats、palettes、.pxs、history／記憶體預算（含效能守門） |
| 伺服器整合 | `npm run smoke` | REST、MCP、金鑰、速率、還原 |
| 端對端 | `npm run e2e`（Playwright） | 介面、繪圖、匯出、PWA |
| 視覺回歸 | 截圖比對（迭代中導入） | 版面、主題 |
| 效能 | 基準腳本（迭代中導入） | 繪圖延遲、開檔、記憶體 |
| 實機 | 使用者 iPad | Apple Pencil、Safari 實際行為 |

### e2e 測試組（`node scripts/e2e.js --list`）
boot、layout、a11y（1.1.0：觸控目標 ≥ 44pt、無障礙名稱）、draw、select、palette、layers、timeline、view、history、memory（1.3.0：復原記憶體預算）、refs、canvas、export、import、persist、savestate（1.2.0：儲存狀態、故障注入）、notices（1.5.0：加入主畫面／備份提醒、IndexedDB 重連）、focus（1.6.0：專注模式）、quick（1.7.0：一次性吸管／橡皮擦）、taps（1.7.1：同點快速點畫）、isoline（1.8.0：Shift 等角 2:1 鎖角）、longpress（1.9.0：長按吸色）、longpress 延遲／關閉（1.10.0）、ramp 單元（1.11.0）、pwa、cloud、keyboard、diag（1.4.0：診斷資訊、錯誤擷取、Scribble 迴歸）（之後版本新增的組見各版報告）。

故障注入：`store.faults.save = 'quota' | 'error'` 讓 IndexedDB 寫入失敗（僅測試使用）。

### 觸控目標規則（ADR-002）
觸控設定量測所有可見的 button／select／input／工具／選單項目／分頁／影格／cel／歷史項目 ≥ 44×44 CSS px；例外：調色盤色塊、主次色塊、標籤條、核取方塊與滑桿本體。

## 2. 自動化裝置矩陣
iPad Pro 11、iPad（第 7 代）、iPad mini（橫／直，WebKit）；iPhone 14（橫／直）；桌面 1920×1080（Chromium）。每個設定測完整伺服器與純靜態 dist/。

## 3. iPad 實機清單（每輪評比執行）
最新完整清單見最近一份 `docs/reviews/review-NN.md` §4。固定項目：
- Apple Pencil 快速點畫（同一列 20 下）與快速短撇：一筆都不能漏（Scribble「隨手寫」開／關各測一次，ADR-005）
- 診斷資訊可複製／下載
- Apple Pencil：筆畫延遲、斜線平滑、手掌放在螢幕上不會誤畫、懸停預覽
- 手勢：雙指捏合縮放、雙指平移、（實作後）雙指復原
- Safari 分頁與主畫面 PWA 皆可開啟、離線可用
- 匯出存到「檔案」App、從「檔案」App 開啟 .pxs
- 外接鍵盤快捷鍵
- 分割畫面／Stage Manager 視窗縮放
- 長時間使用（30 分鐘）不卡頓、不遺失資料

- R10：漸層（線性／放射／硬邊）觸控拖曳與預覽流暢度；iPadOS 27 觸控效能。
- R7：『加外框』選單點擊與復原；Pencil 懸停預覽與快速筆畫平滑度（Pencil Pro）。

## 4. 效能基準（初版目標）

|---|---|
