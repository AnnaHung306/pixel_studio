# 05 測試計畫

## 1. 測試層級
| 層級 | 工具 | 範圍 |
|---|---|---|
| 單元 | node:test（迭代中導入） | core/raster、formats |
| 伺服器整合 | `npm run smoke` | REST、MCP、金鑰、速率、還原 |
| 端對端 | `npm run e2e`（Playwright） | 介面、繪圖、匯出、PWA |
| 視覺回歸 | 截圖比對（迭代中導入） | 版面、主題 |
| 效能 | 基準腳本（迭代中導入） | 繪圖延遲、開檔、記憶體 |
| 實機 | 使用者 iPad | Apple Pencil、Safari 實際行為 |

## 2. 自動化裝置矩陣
iPad Pro 11、iPad（第 7 代）、iPad mini（橫／直，WebKit）；iPhone 14（橫／直）；桌面 1920×1080（Chromium）。每個設定測完整伺服器與純靜態 dist/。

## 3. iPad 實機清單（每輪評比執行）
- Apple Pencil：筆畫延遲、斜線平滑、手掌放在螢幕上不會誤畫、懸停預覽
- 手勢：雙指捏合縮放、雙指平移、（實作後）雙指復原
- Safari 分頁與主畫面 PWA 皆可開啟、離線可用
- 匯出存到「檔案」App、從「檔案」App 開啟 .pxs
- 外接鍵盤快捷鍵
- 分割畫面／Stage Manager 視窗縮放
- 長時間使用（30 分鐘）不卡頓、不遺失資料

## 4. 效能基準（初版目標）
| 情境 | 目標 |
|---|---|
| 64×64 單影格筆畫 | < 4ms/事件 |
| 256×256、10 圖層、50 影格筆畫 | < 16ms/事件 |
| 開啟 256×256×50 影格 .pxs | < 2s |

## 5. 回歸規則
修 bug 必附重現測試；任一測試失敗不得發布。
