# 02 工作流與版本規則

## 1. 每次迭代標準流程（一次迭代 = 一個版本）
1. **選題**：從 03-迭代路線圖 的 backlog 取最高優先項目（bug > iPad 體驗 > 評比發現的缺口 > 新功能）。
2. **設計**：寫下目標、範圍、影響模組；重大決策新增 ADR。
3. **實作**：小步提交；保持零 console error。
4. **測試**：
   - `npm run build`、`npm run smoke`（伺服器 API／MCP）
   - `npm run e2e`（WebKit iPad Pro 11／iPad 第 7 代／iPad mini 橫直向、iPhone、桌面 Chromium）
   - 新功能必須新增對應測試；修 bug 必須先寫能重現的測試。
   - 效能基準（05-測試計畫 §4）不得退步超過 10%。
5. **文件**：更新 CHANGELOG、相關 SE 文件、使用說明書、QA 測試報告。
6. **發布**：依下列規則定版號 → 更新 `package.json` version → 一個 commit（訊息 `vX.Y.Z: 摘要`）→ 打 tag `vX.Y.Z` → 推到 `main`。

### Definition of Done
- [ ] 所有自動化測試通過、無 console error／warning
- [ ] 新增／修改的行為有測試覆蓋
- [ ] CHANGELOG 與相關文件已更新
- [ ] 版本號與 tag 正確

### 工具（迭代 1 起）
| 指令 | 用途 |
|---|---|
| `npm run e2e:par` | 全矩陣 e2e 分 N 個行程平行跑（結果與 `npm run e2e` 相同，CI／發布前使用） |
| `work/tools/e2e-grp.sh <dir> A…E` | 沙箱內發布用：全矩陣切 5 段（每段 ≤ 約 11 分），兩段並行；避免單一背景工作超過 20 分鐘被終止 |
| `node scripts/e2e.js --profile=… --suite=…` | 開發中只跑相關組 |
| `python3 work/bump.py X.Y.Z` | 同步 package.json／package-lock.json 版本；`npm run build` 會把版本寫入 `public/js/version.js`（前端唯一版本來源）與 Service Worker 快取名 |
| `python3 work/release_docs.py spec.json` | 依測試結果產生 CHANGELOG、進度表、QA 報告、使用說明書版本、`docs/releases/vX.Y.Z.md`；測試未全過會中止 |
| `python3 work/gh_release.py X.Y.Z "摘要"` | 一個 commit＋annotated tag 推到 main |

版本號單一來源：`package.json`。伺服器（`server/version.js`）與前端（建置產生的 `public/js/version.js`）都由它衍生，禁止在程式中寫死版本字串（smoke／e2e 會檢查）。

## 2. 版本號規則（自 1.0.0 起）
| 變更類型 | 例子 | 版本 |
|---|---|---|
| 整體大改進 | 新檔案格式、架構重寫、互動模型改版、Aseprite 相容層 | **X**+1.0.0 |
| 小幅度優化／新功能 | 新工具、新匯出格式、UI 改善、效能優化 | X.**Y**+1.0 |
| 修正 bug | 任何錯誤修正（不含新功能） | X.Y.**Z**+1 |

同一次迭代若同時包含多種，取最高等級。

## 3. 每 5 次迭代：橫向評比與盲點搜尋
1. 對照競品（Aseprite、Pixaki、Resprite、Pixquare、Piskel、Lospec、Pixilart）功能與操作流程，填寫評比矩陣。
2. 上網搜尋：使用者評論、論壇（Reddit r/PixelArt、Aseprite 社群）、iPadOS Safari 新版的 PWA／Pointer Events 已知問題、像素藝術工作流的最佳實務。
3. 產出 `docs/reviews/review-NN.md`：差距、盲點、決定採納項目，回填到 backlog。

## 4. iPad 實機驗證
- 自動化：Playwright WebKit（Safari 引擎）+ iPad 裝置設定，觸控與 `pointerType: pen` 合成事件。
- 實機：每輪評比部署測試版（Zeabur），由使用者在 iPad 上依 05-測試計畫 §3 的實機清單驗證（Apple Pencil 手感、防誤觸、懸停、「檔案」App、主畫面 PWA），結果回填 QA 報告。
