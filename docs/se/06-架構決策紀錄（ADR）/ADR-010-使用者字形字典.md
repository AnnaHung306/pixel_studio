# ADR-010 使用者字形字典
- 狀態：採用（1.51.0）
- 背景：使用者要自行新增字形（轉換器、手繪、選取區），跨專案共用，打字時優先使用。
- 決策：
  - 全域字典存於獨立 IndexedDB `pixel-studio-glyphs`（store `glyphs`，key = `px:codepoint`），與專案資料庫分開，避免專案庫重置時遺失。
  - 記錄：`{px, cp, ch, rows[16-bit × px], adv, src, t}`，與內建字型列編碼相同，渲染無需轉換；寬度上限 16。
  - 以像素高度（字型 size）＋字元為鍵；不分繁簡（同字元同大小只有一個）。
  - 查找順序：使用者字典 → 內建字型 → 轉換器 fallback → 缺字框。
  - 儲存後端以 `setBackend` 注入，核心邏輯（core/glyphdict.js）可在 Node 單元測試。
  - 匯出／匯入為 JSON（`app:"pixel-studio-glyphs"`，rows 為十六進位字串），匯入合併並略過無效記錄。
- 後果：字典不進 .pxs（後續待辦）；IndexedDB 不可用時退回內建字型。
