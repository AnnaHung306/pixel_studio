# ADR-008 像素字型格式與按需載入（文字工具）
- 狀態：採納（1.48.0）
- 背景：使用者要求文字工具可直接打繁中／簡中／英文，依像素大小選字型、有多種風格（B59–B64）。
- 決策：
  - 字型來源只用 SIL OFL 1.1：Fusion Pixel Font（TakWolf，12px 等寬，zh_TW／zh_Hans 字形版本）；後續加 8/10px、Cubic 11、GNU Unifont（取 OFL）。**禁用 Zpix（商用付費、禁止轉換）**。授權檔隨 App 放在 `public/fonts/OFL.txt`。
  - 格式：build 前以 `work/tools/bdf2slices.py` 把官方 release 的 BDF 轉成「每 4096 個碼位一片」的 JSON：`{h,a,g:{十六進位碼位:"字寬:每列4位十六進位×H列"}}`，MSB 為最左像素。每語言約 2.2 MB（gzip 後大幅縮小），單片 ≤ ~150 KB。
  - 載入：`core/pixelfont.js` 以 fetch 按需載入需要的片（輸入文字所在的碼位區塊），記憶體快取；Service Worker 對同源 GET 採 cache-first 並於執行期寫入快取，故用過的片離線仍可用。字型檔不進 precache（`scripts/build.js` 排除 fonts/，但仍納入版本雜湊），避免首次安裝下載數 MB。
  - 寫入：文字轉成浮動選取（label「文字」），沿用既有拖曳／完成／取消／復原機制；一次寫入＝一筆歷史。
  - 缺字：以 U+FFFD 或空白字寬佔位；後續迭代接轉換器（B61）與使用者字典（B62，查找順序：使用者字典 → 內建字型 → 轉換器）。
- 替代方案：用 WOFF2 向量字型＋Canvas 在 12px 渲染（會有反鋸齒、不保證像素銳利）；全量字型 precache（首裝過大）。
- 影響：新增 `public/fonts/`（約 4.4 MB，按需下載）；專案格式不變。

- 1.49.0 補充：FONTS 註冊表加入 fusion8m／fusion10m／fusion12p（皆 OFL）；`pickFont(size, style)` 取最接近的大小，風格不存在則退回等寬；字高由字型 `h` 決定。Bold、Cubic 11、Unifont 待後續。
