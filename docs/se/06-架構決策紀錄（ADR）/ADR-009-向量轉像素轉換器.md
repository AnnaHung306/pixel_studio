# ADR-009 向量→像素字形轉換器（1.50.0）

狀態：採用

## 背景
內建 Fusion Pixel 字型缺字時（罕用字、符號），文字工具只能留空白。使用者要求自製轉換器，把向量字轉成乾淨像素字。

## 決策
- `core/glyphconv.js` 為純函式：由 rasterizer callback 提供 8-bit 覆蓋度（可注入，單元測試不需瀏覽器），瀏覽器端以 Canvas `fillText`（PingFang TC → Noto Sans TC → 系統無襯線）渲染。
- 流程：①子像素偏移搜尋（0／.25／.5／.75 的 x、y 共 16 組），取「覆蓋度離 128 最遠」（crispness 最大）者＝最貼齊像素格；②門檻二值化；③細筆畫保留：覆蓋度≥keep 且在水平或垂直方向為局部極大、該軸無實心鄰點、且與實心像素相連者補成 1px；④去孤立點：無 8 鄰居且覆蓋度<230 者移除。
- 缺字 fallback：`pixelfont.setFallback(fn)`，`ensureText` 對缺字呼叫 fn 並以 (px,codepoint) 快取，`renderText` 查找順序：字型 → 轉換器快取 → U+FFFD → 空白。僅 BMP（>U+FFFF 頁不出貨，不再發出 404 請求）。
- 轉換器對話框：輸入文字、像素大小 8–32、門檻、細筆畫保留、對齊／去孤點開關；預覽格可點選手修；「放到畫布」以浮動選取放置（主色）。
- 使用者字典（B62）將以 (字元, 像素大小) 為鍵存入轉換結果；本版尚未持久化。

## 後果
轉換結果品質取決於系統字型（iPad 有 PingFang TC）；字形≤16px 才能走 fallback 的 16-bit 列編碼。
