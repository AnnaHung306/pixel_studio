# ADR-004：本機診斷資訊與錯誤擷取（不自動上傳）
- 狀態：採納（1.4.0）
- 背景：使用者在 iPad 上無法開啟開發者工具，實機問題（Apple Pencil 漏筆、儲存失敗、離線快取）無從追查。商業產品需要可回報的診斷資訊，但隱私上不能預設傳送任何資料。
- 決定：
  1. `diag.js` 保存最近 100 筆紀錄（環狀）：全域 `error`／`unhandledrejection`、資源載入失敗、自動儲存失敗、啟動。
  2. 「☰ → 診斷資訊」顯示版本、裝置／顯示（含主畫面模式、觸控 UI）、離線快取、儲存空間與持久儲存、專案規模（不含像素）、復原歷史、儲存狀態、伺服器狀態與最近紀錄；可「複製」（失敗時選取文字讓使用者長按拷貝）或「下載診斷檔」（JSON）。
  3. 絕不自動上傳；選擇性的遠端錯誤追蹤留待階段 E（opt-in）另立 ADR。
  4. 發生錯誤時以提示（10 秒內最多一次）引導使用者到診斷資訊。
- 後果：iPadOS 26 Safari 的 UA 版本號凍結，診斷資訊提示使用者自行填寫 iPadOS 版本。
