# 01 產品需求規格

## 1. 產品定位
商業級、觸控優先（iPad + Apple Pencil 為第一優先）的像素繪圖與動畫工具，以瀏覽器 PWA 形式交付，可離線、可安裝到主畫面；附選用的本機伺服器提供 AI（REST／MCP）協作與多裝置同步。

對標：Aseprite（桌面標竿）、Pixaki、Resprite、Pixquare（iPad 原生）、Piskel、Lospec Pixel Editor、Pixilart（網頁）。

## 2. 目標使用者
1. 獨立遊戲開發者：角色／tileset／動畫，需要精靈圖與引擎（Godot／Unity）相容匯出。
2. 像素插畫家：重視調色盤、抖動、筆感、參考圖。
3. 學生與入門者：需要清楚上手引導、範本、教學。
4. AI 協作使用者：用 MCP／REST 讓 AI 繪製、修改、批次產生。

## 3. 功能需求（FR，持續擴充）
- FR-1 繪圖：鉛筆、橡皮擦、填色、形狀、選取、移動、對稱、像素完美、抖動筆刷。
- FR-2 顏色：調色盤管理、色階（ramp）、索引色模式、透明度。
- FR-3 圖層：群組、混合模式、鎖定、參考圖層。
- FR-4 動畫：cel、影格時長、標籤（tag）、洋蔥皮、播放模式、連結 cel。
- FR-5 檔案：.pxs 原生格式、PNG/APNG/GIF/精靈圖+JSON、Aseprite .ase/.aseprite 匯入匯出、自動儲存與當機復原。
- FR-6 iPad：Apple Pencil 壓力／懸停／雙擊、手勢（雙指復原、三指重做、捏合）、分割畫面、外接鍵盤快捷鍵、「檔案」App。
- FR-7 AI 協作：REST、MCP、金鑰權限、活動紀錄、一鍵還原、不得刪除。
- FR-8 上手：新手引導、範本、說明。

## 4. 非功能需求（NFR）
- NFR-1 效能：256×256、50 影格、10 圖層下繪圖延遲 < 16ms（60fps），開啟 < 2s。
- NFR-2 可靠性：任何操作都可復原；自動儲存；資料不因 Safari 清除策略遺失（提示匯出／持久儲存）。
- NFR-3 相容性：iPadOS Safari 17+、主畫面 PWA、Chrome／Edge／Safari 桌面。
- NFR-4 無障礙：觸控目標 ≥ 44pt、對比、VoiceOver 標籤、繁中／英文介面。
- NFR-5 安全：API 金鑰最小權限、伺服器端禁止刪除、速率限制。
- NFR-6 品質：每版 smoke + e2e 全過才可發布；無 console error。

## 5. 驗收
每個 FR 在 05-測試計畫 中都有對應的自動化或手動測試案例。
