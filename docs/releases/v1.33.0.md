# v1.33.0 版本報告

- 日期：2026-10-28　迭代：42　類型：優化／新功能（次版號）
- 主題：預覽視窗顯示游標所在像素（B42）

## 改了什麼
- **新增**：預覽面板會在游標所在的像素上畫出黑白雙框標記，縮小預覽時也能看出正在畫哪裡；游標離開畫布即消失
- **測試**：新增 pvmark 組：hover 事件攜帶文件座標、離開時清除、預覽標記像素

## 為什麼
R8 評比：縮放到很大時看不到整體位置，預覽標記可協助定位。
