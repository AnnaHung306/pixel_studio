# v1.13.0 版本報告

- 日期：2026-10-27　迭代：21　類型：優化／新功能（次版號）
- 主題：無縫拼貼預覽（B26）

## 改了什麼
- **新增**：「檢視」選單新增「無縫拼貼預覽」：在畫布周圍以半透明顯示 8 個相鄰重複，方便檢查地磚／材質接縫
- **測試**：e2e 新增 tile 組（開關預覽、版面、繪圖不受影響）

## 為什麼
像素地磚／材質需檢查邊緣是否可無縫銜接，這是 Aseprite、Pixaki 的常用功能（R4 評比缺口）。
