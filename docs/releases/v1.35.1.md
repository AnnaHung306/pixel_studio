# v1.35.1 版本報告

- 日期：2026-10-28　迭代：44　類型：修正（修訂號）
- 主題：調色還原按鈕：還原後立即重繪（修 1.35.0 直式偶發殘留）

## 改了什麼
- **修正**：調色還原按鈕點擊後立即重繪並隱藏，不再等下一個動畫影格（1.35.0 在直式負載下偶爾殘留一幀，導致 e2e 失敗）
- **測試**：colorrevert 組改為輪詢等待隱藏狀態

## 為什麼
1.35.0 發布時直式 6 個 e2e 檢查失敗（還原後按鈕未即時隱藏）；此版修正並以全矩陣重新驗證。
