# v1.54.1 版本報告

- 日期：2026-10-31　迭代：64　類型：修正（修訂號）
- 主題：IME 輸入修正與離線字型測試

## 改了什麼
- **修正**：文字工具：注音／拼音選字過程（composition）中不再重繪預覽，確認後才一次渲染，避免半成品注音符號閃爍
- **測試**：e2e 新增 textime 組（IME composition 事件模擬）；e2e 新增 textoffline 組（字型分片由 Service Worker 快取，離線重載後文字渲染一致）

## 為什麼
文字工具規格要求支援注音／拼音 IME 與離線使用；補上驗證並修正選字中途的預覽閃爍。
