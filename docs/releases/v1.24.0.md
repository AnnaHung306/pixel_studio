# v1.24.0 版本報告

- 日期：2026-10-28　迭代：32　類型：優化／新功能（次版號）

## 改了什麼
- **新增**：選取工具列新增「設為筆刷」：把選取範圍的形狀（上限 64×64）設為筆刷，以目前顏色蓋印；筆刷形狀多一個 ◆ 按鈕可切換，設定會保存
- **測試**：e2e 新增 custombrush 組（建立、切換、蓋印形狀）
