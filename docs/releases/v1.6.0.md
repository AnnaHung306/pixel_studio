# v1.6.0 版本報告

- 日期：2026-10-27　迭代：7　類型：優化／新功能（次版號）
- 主題：專注模式：一鍵隱藏面板、畫布最大化（ADR-007）

## 改了什麼
- **新增**：專注模式（B11）：頂端列「⛶」、☰ →「專注模式」或 Tab 鍵進入；隱藏頂端列、選項列、側邊面板、時間軸與提示列，只留工具列、畫布與左上角浮動小工具（復原／重做／離開專注，44pt）；進入／離開後畫布自動符合視窗；手機版開啟中的面板會一併收起；快捷鍵說明新增 Tab；e2e `focus` 組（19–20 項）

## 為什麼
第 1 輪評比發現 iPad 畫布空間被面板佔用（B11）；Pixaki、Procreate 類 App 都提供一鍵專注。專注模式讓 iPad 直向／mini 繪圖時畫布最大化，同時保留工具與復原，不需先退出才能修正。

## iPad 影響
iPad 直向與 mini 畫布可用面積明顯增加；浮動小工具按鈕 ≥ 44pt；專注狀態不跨重新載入（避免使用者找不到面板）。手機版沿用選單進入。

## 已知問題
專注模式下不顯示色彩編輯器（需離開專注換色，或點工具列主要色）；尚無手勢呼出面板。
