# v1.50.0 版本報告

- 日期：2026-10-30　迭代：59　類型：優化／新功能（次版號）
- 主題：文字工具（第三部分）：向量→像素轉換器與缺字自動轉換

## 改了什麼
- **新增**：文字工具新增「🔤 轉換器」：輸入文字、選 8–32px，以系統向量字型渲染後轉成乾淨 1-bit 點陣（自動對齊像素格、細筆畫保留、去孤立點，門檻可調），預覽格可點選手修，再「放到畫布」；內建字型缺字時自動以轉換器產生字形（依字型像素大小並快取），不再留空白；罕用字（U+FFFF 以上）不再發出字型切片 404 請求
- **測試**：glyphconv 單元測試 5 項（門檻、細筆畫保留、去孤點、對齊搜尋、列編碼）；conv e2e 組（開啟、預覽、門檻、手修、雙字、放置、缺字不崩潰）

## 為什麼
使用者要求自製向量→像素轉換器並可預覽手修；內建字型缺字時需自動 fallback。本版完成規格 B，字典持久化留待迭代 60。

## iPad 影響
轉換依賴 iPad 內建 PingFang TC；預覽格點選目標為 4–16px 縮放格，可用手指或 Pencil 修點。

## 已知問題
轉換結果尚不能存入字典（迭代 60）；fallback 僅支援 ≤16px 字型；Bold／Cubic 11／Unifont 尚未加入。
