# v1.3.0 版本報告

- 日期：2026-10-27　迭代：4　類型：優化／新功能（次版號）
- 主題：復原歷史記憶體預算（ADR-003）＋單元測試層 npm test

## 改了什麼
- **新增**：復原歷史以記憶體預算限制（iPad 96 MB／低記憶體裝置 128 MB／其他 320 MB），超過時自動移除最舊步驟、保留最新 10 步並提示一次；AI／遠端同步寫入同樣計入；歷史紀錄面板顯示「N 步 · 復原記憶體 X / Y MB · 已移除最舊 K 步」；單元測試層 `npm test`（node:test，22 項）：raster 核心、GIF／ZIP／CRC、調色盤檔、.pxs、歷史與記憶體預算，含 256×256×10 圖層×50 影格的 commit 效能守門；e2e `memory` 測試組
- **變更**：歷史步數上限 120 → 200（記憶體預算才是真正限制）

## 為什麼
iPadOS Safari 會在分頁記憶體過高時直接重新載入頁面，對使用者等於作品不見；1.0 只以步數限制歷史，大畫布、多影格時無法控制記憶體。同時專案缺少單元測試層（05 測試計畫列為迭代中導入）。

長時間在 iPad 上編輯大型動畫不再因復原歷史吃光記憶體而被 Safari 重載；面板可看到目前用量。
