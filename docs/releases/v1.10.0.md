# v1.10.0 版本報告

- 日期：2026-10-27　迭代：15　類型：優化／新功能（次版號）
- 主題：長按吸色可調：0.4／0.6／0.9 秒或關閉，設定會記住

## 改了什麼
- **新增**：選單「長按吸色」可切換延遲 0.4／0.6／0.9 秒或關閉，設定隨偏好保存（B12 收尾）
- **測試**：longpress 組新增：關閉時不吸色、0.4 秒延遲生效

## 為什麼
長按吸色對慣用長停頓畫點的使用者可能誤觸，需可調或關閉。
