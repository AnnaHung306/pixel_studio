# v1.36.0 版本報告

- 日期：2026-10-28　迭代：45　類型：優化／新功能（次版號）
- 主題：移動工具環繞模式（無縫 tile）

## 改了什麼
- **新增**：移動工具新增「🔁 環繞移動」開關：移出邊界的像素會從另一側出現，方便製作無縫 tile；單次復原，設定會記憶
- **測試**：新增 wrapmove 組：環繞進入對側、原位清除、復原、關閉時裁切

## 為什麼
搭配 1.13.0 無縫 tile 預覽，需要能環繞位移以檢查並修正接縫。
