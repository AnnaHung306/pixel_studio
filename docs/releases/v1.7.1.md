# v1.7.1 版本報告

- 日期：2026-10-27　迭代：9　類型：修正（修訂號）
- 主題：同點快速重複點畫守門測試（B13）

## 改了什麼
- **測試**：新增 e2e `taps` 組：畫布 touch-action 必須為 none（避免雙擊縮放）、同一格連續快速點畫必須全部登錄、真實觸控／滑鼠雙擊可畫

## 為什麼
第 1 輪評比指出 iPad Safari 的雙擊縮放判定可能吃掉同點快速重複點擊；先以測試守住，實機驗證留待評比清單。
