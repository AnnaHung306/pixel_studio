# v1.39.0 版本報告

- 日期：2026-10-29　迭代：48　類型：優化／新功能（次版號）
- 主題：漸層填充（抖動漸層）

## 改了什麼
- **新增**：油漆桶新增「🌗 漸層」開關：拖曳決定方向，在填充區域內以有序抖動畫出主色→副色漸層；點一下仍為單色填滿；拖曳時即時預覽，一次操作一步復原；支援選取範圍、相連／全部同色、調色盤鎖定
- **測試**：新增 gradfill e2e 組與 gradient 單元測試（區域、端點色、僅兩色）

## 為什麼
B50：像素畫常用抖動漸層做天空與陰影，手動點畫耗時；以拖曳方向一次完成。
