# v1.18.0 版本報告

- 日期：2026-10-27　迭代：26　類型：優化／新功能（次版號）
- 主題：鎖定調色盤（繪圖色吸附到最近的調色盤顏色）

## 改了什麼
- **新增**：鉛筆／橡皮擦選項新增「🔒 鎖定調色盤」：繪圖色自動吸附到最近的調色盤顏色（保留 alpha），偏好會保存
- **測試**：unit 新增 nearestPaletteColor；e2e 新增 palettelock 組

## 為什麼
確保作品嚴格使用調色盤（PaletteGuard 類需求，R5 盲點 5），是索引色模式的第一步。
