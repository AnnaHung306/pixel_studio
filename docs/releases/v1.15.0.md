# v1.15.0 版本報告

- 日期：2026-10-27　迭代：23　類型：優化／新功能（次版號）
- 主題：色階墨水 Shading ink（B18 餘項）

## 改了什麼
- **新增**：鉛筆選項列新增「墨水」：加深／加亮——在已有顏色的像素上畫過會變暗／變亮一階（含色相偏移），空白像素不受影響；記住偏好
- **測試**：e2e 新增 shadeink 組（加深、不畫空白、加亮）

## 為什麼
評比缺口：Aseprite 的 shading ink 是像素畫家上色階的核心工作流。
