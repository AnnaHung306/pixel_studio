# v1.22.0 版本報告

- 日期：2026-10-28　迭代：30　類型：優化／新功能（次版號）
- 主題：快速色盤（B29）

## 改了什麼
- **新增**：畫布右上角新增「色」按鈕：開啟浮動快速色盤，點色即設為主要顏色，不必離開畫布或開側欄（專注模式也可用）
- **測試**：e2e quick 組新增快速色盤開關與選色檢查；快速按鈕 44pt 檢查改為 3 顆

## 為什麼
iPad 繪圖時換色要頻繁，浮動色盤減少手移動與面板切換（評比 R5 缺口 B29）。
