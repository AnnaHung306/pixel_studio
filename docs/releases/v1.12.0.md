# v1.12.0 版本報告

- 日期：2026-10-27　迭代：17　類型：優化／新功能（次版號）
- 主題：色彩明暗一階（< / > 快捷鍵與按鈕）

## 改了什麼
- **新增**：色彩編輯器新增「◐ 較暗／◑ 較亮」按鈕與 < / > 快捷鍵：沿含色相偏移的色階將目前顏色調暗或調亮一階，保留透明度（B18 第二步）
- **測試**：單元測試新增 shadeStep：亮度方向、alpha 保留、數值範圍

## 為什麼
上色時常需要快速取同色系的陰影／高光，不必開色盤或調 HSV。
