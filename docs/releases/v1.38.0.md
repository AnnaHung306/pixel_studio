# v1.38.0 版本報告

- 日期：2026-10-29　迭代：47　類型：優化／新功能（次版號）
- 主題：雙指／三指點按復原：回饋提示與開關

## 改了什麼
- **新增**：雙指點按復原／三指點按重做後顯示提示（含「沒有可復原的步驟」），方便確認手勢生效；「更多」選單新增「雙指／三指點按復原」開關，可關閉以避免誤觸，設定會保存
- **測試**：新增 tapgest 組：預設開啟、關閉時忽略、開啟時復原並顯示提示、三指重做

## 為什麼
B49：手勢本身已存在，但沒有回饋也無法關閉；手掌或多指誤觸時使用者不知道發生什麼事。
