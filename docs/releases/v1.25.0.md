# v1.25.0 版本報告

- 日期：2026-10-28　迭代：34　類型：優化／新功能（次版號）
- 主題：精靈圖影格間距（B35）

## 改了什麼
- **新增**：匯出精靈圖新增「間距」欄位（0–64 像素）：影格之間與邊緣留透明間距，避免遊戲引擎縮放時紋理滲色；JSON 的 meta.padding 一併記錄，frame 座標已含間距
- **測試**：單元測試新增 sheetGeometry 2 項

## 為什麼
遊戲引擎匯入精靈圖常需影格間距防止紋理滲色（Aseprite 有 Spacing／Border）。
