## 改了什麼
- **新增**：移動工具新增「🔗 連動所有圖層」開關：開啟後拖曳會同時移動此影格所有可見且未鎖定的圖層，一次復原即可還原；設定會記憶
- **測試**：新增 linkmove 組：未連動只動作用圖層、連動時全部圖層位移、單次復原還原

## 為什麼
R8 評比：調整整體構圖時需逐層移動，連動移動可一次對位。
