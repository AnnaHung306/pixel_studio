## 改了什麼
- **新增**：長按／右鍵色塊 →「命名顏色…」：為調色盤顏色加名稱，色塊提示與 VoiceOver 標籤會顯示名稱（可復原、隨專案保存）；匯出 .gpl 會寫入顏色名稱；匯入 .gpl 會讀回名稱
- **測試**：新增 palnames 單元測試（GPL 名稱往返）與 palname e2e 組

## 為什麼
Aseprite 社群常見需求：有名稱的調色盤（如「磚紅」「天空藍」）便於跨專案溝通與交換。
