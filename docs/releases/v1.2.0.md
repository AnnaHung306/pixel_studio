# v1.2.0 版本報告

- 日期：2026-10-27　迭代：3　類型：優化／新功能（次版號）
- 主題：儲存狀態指示、自動儲存失敗（空間不足）橫幅＋備份＋自動重試

## 改了什麼
- **新增**：專案名稱前的儲存狀態圓點：綠＝已儲存、黃＝未儲存／儲存中、紅＝失敗；VoiceOver 透過 live region 播報；自動儲存失敗時顯示紅色橫幅：說明原因（空間不足／其他），提供「下載 .pxs 備份」「重試」「管理專案」；失敗後以 4s 起倍增（上限 60s）自動重試；儲存空間使用超過 80% 時提示一次；「關於」顯示已用／可用空間與持久儲存狀態、最後儲存時間；離開頁面前若有未儲存或失敗的變更，桌面瀏覽器會提示；e2e `savestate` 測試組：以故障注入模擬 QuotaExceededError，驗證橫幅、備份下載、重試、重新整理後資料完整
- **變更**：自動儲存改為狀態機（saved → dirty → saving → saved／error），儲存中又有變更時會接續儲存，不會遺漏最後一筆
- **修正**：1.0 自動儲存失敗只寫 console，使用者完全不知道作品沒存到（iPad 空間不足時會遺失作品）

## 為什麼
NFR-2 可靠性：iPad 儲存空間不足或 Safari 清除策略都可能讓 IndexedDB 寫入失敗，而 1.0 對使用者完全靜默。商業級 App 必須讓使用者隨時知道作品是否已安全儲存，並在失敗時提供立即可行的退路（下載備份）。

## iPad 影響
iPad 上可一眼看到是否已儲存；空間不足時橫幅按鈕皆為 44pt，「下載 .pxs 備份」在主畫面 App 會開啟分享面板存到「檔案」。

## 已知問題
Safari 不支援 beforeunload 提示（iPad 關閉分頁時無法攔截），以即時儲存與橫幅彌補；儲存空間估計值由瀏覽器提供，可能不精確。
