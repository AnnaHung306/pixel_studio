# v1.9.0 版本報告

- 日期：2026-10-27　迭代：14　類型：優化／新功能（次版號）
- 主題：長按吸色：手指／Apple Pencil 在畫布按住不動 0.6 秒即吸取顏色

## 改了什麼
- **新增**：鉛筆／橡皮擦時，手指或 Apple Pencil 在同一點按住不動約 0.6 秒，會取消該筆並吸取該格顏色（B12 後續）
- **測試**：e2e 新增 longpress 組：長按吸色、短點仍可繪圖

## 為什麼
iPad 上沒有 Alt 鍵，吸色需切換工具；長按吸色讓單手流程不中斷（Procreate／Pixaki 慣例）。

## iPad 影響
手指與 Pencil 皆適用；移動超過 8px、第二指落下或筆畫結束會取消長按。滑鼠不觸發。

## 已知問題
長按延遲固定 0.6 秒，尚不可調；實機手感待迭代 50 後驗證。
