# v1.37.0 版本報告

- 日期：2026-10-29　迭代：46　類型：優化／新功能（次版號）
- 主題：圖層鎖定透明度（α 鎖）

## 改了什麼
- **新增**：圖層列新增 α 按鈕「鎖定透明度」：開啟後筆刷只會改已有像素的顏色，不會在空白處上色，橡皮擦也不會擦除
- **測試**：新增 alphalock 組：按鈕存在、重新著色、空白處不上色、橡皮擦被擋

## 為什麼
像素畫常見的上色／換色流程（Procreate、Aseprite 的 lock alpha），不必切換墨水模式即可持續生效。
