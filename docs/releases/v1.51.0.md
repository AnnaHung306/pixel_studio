# v1.51.0 版本報告

- 日期：2026-10-30　迭代：60　類型：優化／新功能（次版號）
- 主題：文字工具（第四部分）：使用者字形字典與字形編輯器

## 改了什麼
- **新增**：文字工具新增「📖 字典」：全域使用者字形字典（IndexedDB，與專案無關），可搜尋、依像素大小篩選、編輯、刪除、匯出／匯入 JSON；字形編輯器：點或拖曳格子手繪字形（8／10／12／16px），存入字典；轉換器新增「存入字典」（可先手修）；字典管理可「選取區存成字形」；打字查找順序：使用者字典 → 內建字型 → 轉換器
- **測試**：glyphdict 單元測試 3 項（CRUD＋重載、匯出入、裁切）；dict e2e 組（開啟、手繪存入、打字優先使用字典字形、IndexedDB 持久化、匯出入）

## 為什麼
使用者要求轉換器或手繪的字都能存入字典，並在打字時優先使用。本版完成規格 C。

## iPad 影響
字形編輯格可用手指／Pencil 拖曳繪製；字典存於獨立 IndexedDB（pixel-studio-glyphs）。

## 已知問題
字典字形寬度上限 16px；尚未併入 .pxs 備份；字典以字元＋像素高度為鍵，不分繁簡字形。
