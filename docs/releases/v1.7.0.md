# v1.7.0 版本報告

- 日期：2026-10-27　迭代：8　類型：優化／新功能（次版號）
- 主題：臨時橡皮擦／吸管一次性按鈕（B12）

## 改了什麼
- **新增**：畫布右上角「吸」「擦」兩顆 44pt 按鈕：點一下後，下一筆為滴管／橡皮擦，完成後自動回到原工具（單手＋Apple Pencil 不必切換工具列）；再點一次可取消待命；e2e `quick` 組

## 為什麼
第 1 輪評比指出 iPad 沒有 Alt／快捷鍵，吸色與擦除需切換工具列；一次性按鈕讓 Pencil 作畫時快速修正。
