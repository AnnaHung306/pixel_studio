# v1.35.0 版本報告

- 日期：2026-10-28　迭代：44　類型：優化／新功能（次版號）
- 主題：調色編輯「還原」按鈕（B45）

## 改了什麼
- **新增**：顏色面板拖曳 SV／色相／透明度或輸入色碼後，旁邊出現舊色色塊（44pt），一點即還原為編輯前的顏色；從調色盤選色或吸色後自動清除
- **測試**：新增 colorrevert 組：編輯前隱藏、編輯後顯示、點擊還原、還原後隱藏

## 為什麼
調色時拖過頭無法回到原色，只能重新吸色；舊色即時比對與一鍵還原降低試色成本。
