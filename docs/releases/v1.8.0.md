# v1.8.0 版本報告

- 日期：2026-10-27　迭代：12　類型：優化／新功能（次版號）
- 主題：Shift 直線等角 2:1 鎖角（B16）

## 改了什麼
- **新增**：直線工具按住 Shift 時，除 0/45/90° 外新增等角 2:1（約 26.57° 與 63.43°）鎖角，方便畫等角像素藝術
- **測試**：e2e 新增 isoline 組（2:1 與水平鎖角）

## 為什麼
評比 R1 指出等角像素線是像素畫常用需求，Aseprite 等工具均有輔助。
