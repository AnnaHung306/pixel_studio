# v1.55.0 版本報告

- 日期：2026-10-31　迭代：65　類型：優化／新功能（次版號）
- 主題：文字斜體

## 改了什麼
- **新增**：文字工具：新增「正體／斜體」選項，以每 4 列右移 1 個文字像素的合成傾斜產生像素斜體，可與外框／陰影／直排以外效果並用
- **測試**：單元測試 shearItalic；e2e text 組新增斜體尺寸檢查

## 為什麼
像素字型沒有內建斜體；評比的文字工具多提供斜體，補上缺口。
