# v1.52.0 版本報告

- 日期：2026-10-31　迭代：61　類型：優化／新功能（次版號）
- 主題：文字工具打磨：外框／陰影效果、Ctrl/Cmd+Enter 放置

## 改了什麼
- **新增**：文字工具新增「文字效果」：外框（八方向一格，使用副色）與陰影（右下偏移一格，副色），倍率放大時同步放大；文字輸入框按 Ctrl/Cmd+Enter 直接放置文字（輸入法組字中不觸發）；Enter 維持換行
- **測試**：pixelfont 單元測試：外框／陰影尺寸與像素數；text e2e 組新增外框尺寸與 Ctrl+Enter 放置檢查

## 為什麼
完成 B63 的文字外框／陰影，並補上 B65 的鍵盤放置，讓文字在複雜背景上可讀、桌面／藍牙鍵盤操作更快。B64 即時預覽與 B66 對齊先前已具備。
