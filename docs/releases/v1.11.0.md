# v1.11.0 版本報告

- 日期：2026-10-27　迭代：16　類型：優化／新功能（次版號）
- 主題：調色盤一鍵加入色階（含色相偏移）

## 改了什麼
- **新增**：調色盤選單新增「以目前顏色加入色階（7 色，含色相偏移）」：由目前顏色產生由暗到亮的 7 色色階，陰影偏冷、高光偏暖，已存在的顏色不重複加入（B18 第一步）
- **測試**：單元測試新增 ramp：長度、中間色為原色、亮度遞增、極端色（黑／白／灰）與數量夾限

## 為什麼
像素畫的色階（ramp）是上色核心；手動調 7 個顏色費時，Aseprite／Pixaki 皆有類似輔助。
