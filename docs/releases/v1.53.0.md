# v1.53.0 版本報告

- 日期：2026-10-31　迭代：62　類型：優化／新功能（次版號）
- 主題：字典併入 .pxs：自製字形隨專案檔攜帶

## 改了什麼
- **新增**：下載 .pxs 時，若使用者字典有字形，會一併寫入專案檔（glyphs 欄位）；開啟 .pxs 時自動把其中字形合併進本機字典，不覆蓋自己已有的同名字形
- **測試**：glyphdict 單元測試：keep 合併不覆蓋、dictGlyphsForPxs 往返

## 為什麼
換裝置或分享專案時，自製／轉換的字形不會遺失；對應 ADR-010 的匯出入。
