# v1.59.0 版本報告

- 日期：2026-10-31　迭代：69　類型：優化／新功能（次版號）
- 主題：轉換器可匯入 TTF/OTF 字型

## 改了什麼
- **新增**：向量→像素轉換器新增「匯入字型 (TTF/OTF/WOFF)」：以使用者自己的字型轉成像素字，可預覽、手修、存入字典或放到畫布；僅本次使用，可改回系統字型（B71）
- **測試**：e2e conv 組新增匯入 TTF、字型改變轉換結果、重設系統字型

## 為什麼
R13 評比缺口：Pixquare 可用自訂字型；讓使用者的字型也能走轉換器與字典流程（B71）。
