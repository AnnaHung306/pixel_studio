# v1.64.0 版本報告

- 日期：2026-11-02　迭代：74　類型：優化／新功能（次版號）
- 主題：補間（位置／淡出）

## 改了什麼
- **新增**：「編輯」選單新增補間：把目前圖層的 cel 在目前影格與下一個有內容的影格之間，自動產生位置補間的中間影格，或淡出到結尾（B76 簡化版，單次復原）
- **測試**：新增 tween.test.js 單元測試（contentBBox、tweenCel）

## 為什麼
動畫中間格手動逐格移動很費工；先做以 cel 內容邊界框為基準的位置／淡出補間（B76）。
