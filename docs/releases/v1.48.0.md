# v1.48.0 版本報告

- 日期：2026-10-30　迭代：57　類型：優化／新功能（次版號）
- 主題：文字工具（第一部分）：Fusion Pixel 12px 繁／簡／英

## 改了什麼
- **新增**：新「文字」工具（T 鍵）：點畫布選位置，在選項列輸入框打字即時預覽（繁體中文／简体中文／English），可拖曳預覽、✓ 放置寫入圖層（可復原）；內建開源像素字型 Fusion Pixel 12px 等寬（SIL OFL 1.1，附 OFL.txt），繁體（台灣字形）與簡體兩套字形，約 3.6 萬字，依輸入內容按需載入並由 Service Worker 快取；選項：語言字形、整數倍放大 ×1–×4、字距、多行對齊；顏色用目前主色（遵守鎖定調色盤）；新增 tools/bdf2slices.py（BDF → 分片 JSON）與 ADR-008
- **測試**：新增 pixelfont 單元測試（解碼、版面、授權檔）與 text e2e 組（Latin／CJK 版面、簡繁切換、放大、多行、放置寫入、復原）

## 為什麼
使用者新增需求：在 App 內直接打出繁中／簡中／英文像素文字。第一版先打通完整流程（字型格式、按需載入、浮動預覽、寫入），後續迭代再擴充多字型、轉換器與使用者字典。

## 已知問題
