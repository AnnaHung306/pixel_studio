# v1.49.0 版本報告

- 日期：2026-10-30　迭代：58　類型：優化／新功能（次版號）
- 主題：文字工具（第二部分）：多字型、依像素大小自動選字型

## 改了什麼
- **新增**：文字工具新增「字型像素大小」8／10／12px 與「風格」等寬／比例，依選擇自動挑對應 Fusion Pixel 字型（8px 等寬、10px 等寬、12px 等寬、12px 比例），繁／簡兩套字形皆有；字型字高依各字型自行決定（8／10／12／16 列），多行與放大倍率照常運作；字型仍按需載入並由 Service Worker 快取（新增約 11 MB 切片，不進 precache）
- **測試**：pixelfont 單元測試：自動選字型規則、所有字型×語言可渲染；text e2e 新增 8／10px 與比例字型高度檢查、選擇器存在檢查

## 為什麼
使用者要求能依像素大小決定字型、並有不同風格。本版把字型註冊表擴充為多字型並加入自動挑選，UI 以像素大小為主要選項。
